# 动态知识图谱实时接入说明

## 1. 知识图谱是静态还是实时

知识图谱本身并不一定是静态的。通常可以分成两部分：

- 静态部分：本体结构和关系模式，例如 Asset、RiskProfile、MarketSnapshot、AgentWeight、Decision、Memory 等实体类型，以及 HAS_RISK_PROFILE、GENERATES_DECISION、WRITES_TO_MEMORY 等关系。
- 动态部分：持续变化的数据事实，例如最新价格、技术指标、市场状态、事件、Agent 权重和交易结果。

因此金融场景更适合使用“动态知识图谱”：

```text
稳定 schema + 持续更新的时间快照
```

## 2. 本项目当前实现

本项目保留原有静态展示不变，新增了一个实时/准实时知识图谱接口：

```text
GET /api/live-kg/<ticker>
```

例如：

```text
GET /api/live-kg/NVDA
```

该接口会尝试获取最近行情数据，计算：

- 最新收盘价
- 日涨跌幅
- MA20
- MA60
- 20日收益率
- 20日年化波动率
- 60日回撤
- 趋势状态
- 波动状态
- 风险档案

并返回 live triples，例如：

```text
Asset:NVDA - HAS_LIVE_SNAPSHOT -> LiveMarketSnapshot:NVDA_2026-06-05
LiveMarketSnapshot:NVDA_2026-06-05 - HAS_TREND_STATE -> MarketState:StrongUptrend
LiveMarketSnapshot:NVDA_2026-06-05 - HAS_VOLATILITY_STATE -> MarketState:HighVolatility
LiveMarketSnapshot:NVDA_2026-06-05 - HAS_CLOSE_PRICE -> Close:128.42
Asset:NVDA - HAS_RISK_BUCKET -> RiskBucket:high
```

## 3. 前端展示

网页左侧导航新增：

```text
知识图谱 -> 实时图谱
```

该页面支持选择 SPY、AAPL、MSFT、NVDA、TSLA、AMD、QQQ，并刷新实时图谱。

如果 Flask 后端没有运行，页面会显示静态兜底数据，并标注为“静态预览兜底”。如果后端运行并成功获取行情，则显示“已接入后端实时快照”。

## 4. 论文表述

本文采用静态图谱与动态图谱结合的方式。静态图谱用于表示稳定的金融本体结构和历史 Agent 决策链路，动态图谱用于接入最新行情并生成 LiveMarketSnapshot。每次实时刷新都会生成新的市场快照三元组，使 Agent 能够读取最新市场状态作为输入，并在交易后将 Decision、BacktestResult、Memory 和 Reflection 写回图谱，从而形成动态闭环。

## 5. 后续可扩展

- 将 `/api/live-kg/<ticker>` 的结果写入 Neo4j，而不仅是返回前端。
- 增加定时任务，每日收盘后自动写入新的 MarketSnapshot。
- 接入实时新闻或公告，生成 Event 层动态三元组。
- 将 Agent 最新判断实时写回图谱，用于下一轮 Trust Weight 更新。

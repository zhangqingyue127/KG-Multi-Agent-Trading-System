# V3 完整度提升说明

本次将原来的教学样例版知识图谱升级为“日频动态金融决策知识图谱”，重点提升数据量、资产覆盖、状态完整度和决策链路完整度。

## 一、数据量提升

| 模块 | 原版本 | V3 完整版 |
|---|---:|---:|
| 资产数量 | 5 | 20 |
| 行情数据 | 1,870 行 | 22,200 行 |
| 技术指标 | 30 行抽样 | 21,013 行日频 |
| 市场状态 | 30 行抽样 | 21,013 行日频 |
| Agent 信任权重 | 120 行 | 84,052 行日频 |
| 决策与 Risk Veto | 30 行 | 21,013 行日频 |
| 知识图谱三元组 | 510 条 | 513,032 条 |

## 二、资产覆盖提升

V3 资产池覆盖：

- 宽基 ETF：SPY、QQQ、DIA、IWM
- 债券/商品：TLT、GLD
- 科技巨头：AAPL、MSFT、AMZN、GOOGL、META
- 半导体/AI：NVDA、AMD
- 高波动成长：TSLA
- 金融：JPM
- 能源：XOM
- 医疗：UNH、JNJ
- 消费：KO、COST

这样图谱不再只围绕少量科技股，而是包含不同资产类型、行业、波动等级和风险档案。

## 三、市场状态完整度提升

原版本只区分：

```text
Uptrend / Sideways / Downtrend
LowVolatility / MediumVolatility / HighVolatility
```

V3 增加为三层状态：

```text
趋势状态：StrongUptrend / Uptrend / Sideways / Downtrend / StrongDowntrend
波动状态：LowVolatility / MediumVolatility / HighVolatility
动量状态：PositiveMomentum / NegativeMomentum / Overbought / Oversold
```

每个资产每天都会形成一个 `MarketSnapshot`，用于连接市场状态、技术指标、信任权重和仓位决策。

## 四、知识图谱完整度提升

V3 图谱包含以下核心链路：

```text
Asset
  -> BELONGS_TO_SECTOR -> Sector
  -> HAS_ASSET_TYPE -> AssetType
  -> HAS_INVESTMENT_STYLE -> Style
  -> HAS_RISK_PROFILE -> RiskProfile

RiskProfile
  -> HAS_RISK_RULE -> RiskRule

MarketSnapshot
  -> SNAPSHOT_OF -> Asset
  -> HAS_TREND_STATE -> MarketState
  -> HAS_VOLATILITY_STATE -> MarketState
  -> HAS_MOMENTUM_STATE -> MarketState
  -> ASSIGNS_TRUST_WEIGHT -> AgentWeight
  -> GENERATES_DECISION -> Decision

AgentWeight
  -> WEIGHT_OF_AGENT -> Agent

Decision
  -> TARGETS_ASSET -> Asset
  -> HAS_ACTION -> Action
  -> HAS_FINAL_POSITION_BUCKET -> PositionBucket
  -> SUPPORTED_BY_EVIDENCE -> Evidence

RiskVeto
  -> VETOES -> Decision
```

## 五、可用于报告的说法

原始版本主要验证了知识图谱闭环是否可行，属于小规模概念验证。V3 版本将图谱扩展为多资产、长时间跨度、日频动态知识图谱：每个资产在每个交易日都生成市场快照，并将技术指标、趋势状态、波动状态、动量状态、Agent 信任权重、仓位决策和 Risk Veto 结果连接起来。

因此，V3 不再是简单静态关系图谱，而是一个可以支持查询、解释、复盘和后续信任更新的动态金融决策知识图谱。
